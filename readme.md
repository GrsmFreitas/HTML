## Resumo do projeto

O projeto consiste em um site desenvolvido na linguagem HTML, centralizado no arquivo `sites_favoritos`, com foco em demonstrar uma lista simples de sites.
O objetivo principal é manter o código organizado, fácil de executar e de evoluir conforme novas necessidades.

## Objetivo

- Criar um site em HTML com imagens, links e descrições.
- Organizar a lógica em uma estrutura clara e reutilizável.


## Técnicas utilizadas

- HTML 5 para lógica da aplicação e execução principal.
- Estrutura simples de execução, permitindo fácil integração com ambientes locais.

## Como executar

1. Verifique se o HTML 5 está instalado.
2. Abra o terminal na pasta do projeto.
3. Execute:

```bash
html sites_favoritos
```
